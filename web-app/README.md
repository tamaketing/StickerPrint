# พิมพ์สติ๊กเกอร์ (เว็บ) — StickerPrint Web

โปรแกรมพิมพ์สติ๊กเกอร์แบบติดซองฟิล์ม / ใบรายชื่อ ทำงานในเบราว์เซอร์ล้วน
ไม่ต้องติดตั้งโปรแกรม ไม่ต้องมีเซิร์ฟเวอร์อ่านไฟล์ — **ไฟล์ Excel ถูกอ่านในเครื่องผู้ใช้เท่านั้น**

| | |
|---|---|
| ภาษา | HTML / CSS / JavaScript ล้วน (ไม่ต้อง build) |
| อ่านไฟล์ | `.xls`, `.xlsx`, `.xlsm`, `.csv`, `.txt` (SheetJS) |
| ส่งออก | พิมพ์จริง, PDF, PNG (300 dpi) |
| แม่แบบ | Sticker A4 2×5 (แบบเดียวตามตัวอย่าง — เปิดแบบอื่นได้ที่ `onlyTemplate` ใน config) |
| โฮสต์ | Cloudflare Pages (ฟรี) หรือ GitHub Pages |

---

## 1. เริ่มใช้ในเครื่อง (สำหรับทดสอบ)

ต้องมี [Node.js](https://nodejs.org/) เวอร์ชัน 18 ขึ้นไป

```bat
cd web-app
node serve.js
```

แล้วเปิด <http://localhost:5173> — หรือดับเบิลคลิก `start.bat`

> เปิดด้วยการดับเบิลคลิก `app.html` (file://) ไม่แนะนำ เพราะเบราว์เซอร์บางตัวปิดกั้น
> `sessionStorage` / การอ่านไฟล์บางประเภท ให้ใช้เซิร์ฟเวอร์ทดสอบด้านบนแทน

### รหัสผ่านเริ่มต้น

```
sticker2569
```

> ⚠ **ต้องเปลี่ยนก่อนส่งให้ลูกค้า** — ดูหัวข้อ 4

## 2. วิธีใช้งาน (3 ขั้นตอน)

1. **เลือกข้อมูล** — ลากไฟล์ Excel มาวาง หรือกด “เลือกไฟล์…”
   - ระบบเลือกชีตที่มีข้อมูลมากที่สุดให้อัตโนมัติ (เปลี่ยนชีตได้)
   - ค้นหาชื่อ / เลขบัตร / บ้านเลขที่ / ตำบล / ชุมชน และกรองตามตำบลหรือชุมชนได้
   - แถวที่เลขบัตรไม่ครบ 13 หลักจะขึ้นสีเตือน (ยังพิมพ์ได้)
   - ปุ่ม “ลองใช้ข้อมูลตัวอย่าง” สำหรับทดลองโดยไม่ต้องมีไฟล์
2. **เลือกรูปแบบป้าย** — แสดงแม่แบบแบบเดียวคือ “Sticker A4 2×5” (ตามรูปตัวอย่างที่งานใช้)
   - ตั้งค่าให้แสดงทุกแบบอีกครั้งได้: แก้ `onlyTemplate` ใน `js/config.js` เป็น `null`
   - เปลี่ยนโลโก้บนป้ายได้ (จำไว้ในเบราว์เซอร์)
3. **พิมพ์** — กด “ทดลองพิมพ์ 1 หน้า” ก่อน แล้วจึง “พิมพ์ทั้งหมด”
   - ในหน้าต่างพิมพ์ของเบราว์เซอร์: **Margins = None**, ปิด **Headers and footers**, **Scale = 100%**
   - ถ้าป้ายไม่ตรงกระดาษ เปิด “ป้ายไม่ตรงกระดาษ?” แล้วขยับทีละ 0.5 มม. (จำค่าไว้)
   - บันทึกเป็น PDF หรือ PNG (ฝังความละเอียด 300 dpi) ก็ได้

### คอลัมน์ที่รองรับใน Excel

ระบบจับคู่หัวคอลัมน์ให้อัตโนมัติ (ไม่สนตัวพิมพ์เล็ก/ใหญ่) เช่น

`ลำดับ`, `นาม`/`คำนำหน้า`, `ชื่อ`, `นามสกุล`, `เลขบัตรประชาชน`/`ID No.`, `อายุ(ปี)`,
`(ปี)`, `เลขที่`, `บ้านเลขที่`, `หมู่ที่`, `ชุมชน`, `ตำบล`, `อำเภอ`, `จังหวัด`, `วันที่ตรวจ`,
`ขวา`/`R`/`VA/R`, `ซ้าย`/`L`/`VA/L`, `Lens`, `PD`, `อ่านหนังสือ`,
`(- สั้นR/L)`, `(+ ยาวR/L)`, `ADD(R/L)`, `CYL (R/L)`, `AXT (R/L)`,
`คัดกรองโรคตา`, `ปัญหาสายตา`, `สถานที่ตรวจ`

หัวคอลัมน์ชุด “ผลตรวจวัดสายตา” ที่รองรับ:

`ลำดับ` `นาม` `ชื่อ` `นามสกุล` `เลขที่บัตรประชาชน` `อายุ(ปี)` `บ้านเลขที่` `ชุมชน`
`(- สั้นR/L)` `(+ ยาวR/L)` `อ่านหนังสือ` `PD` `VA/R` `VA/L` `คัดกรองโรคตา`
`สถานที่ตรวจ` `วันที่ตรวจ`

- `อายุ(ปี)` และหัว `(ปี)` ของไฟล์เดิมใช้เป็นอายุโดยตรง ถ้าไม่มีคอลัมน์อายุ
  จึงคำนวณจากปีเกิด (`ปีเกิด` / `birthyear`) และถ้าไม่มีปีเกิด ระบบประมาณปีเกิด
  จากอายุกับปีที่ตรวจให้เฉพาะ token `{{birthyear_be}}`
- `ชุมชน` ถูกนำไปแสดงในที่อยู่ และใช้เป็นตัวกรองแทนตำบลเมื่อไฟล์ไม่มีตำบล
- วันที่ที่จัดรูปแบบเป็นปี 2 หลัก (เช่น `10/20/69` หรือ `2/2/18`) ระบบตีความทั้ง ค.ศ.
  และ พ.ศ. โดยเลือกปีที่ใกล้ปีปัจจุบันที่สุดและไม่เป็นอนาคตเกิน 1 ปี

ถ้าหัวคอลัมน์ไม่ตรง ระบบยังเก็บค่าดิบไว้ และใช้ชื่อคอลัมน์เป็น token ได้ เช่น `{{ชื่อ}}`

### Token ที่ใช้ในแม่แบบ

`{{no.}}` `{{no3}}` `{{title}}` `{{firstname}}` `{{lastname}}` `{{fullname}}`
`{{idno}}` `{{birthyear}}` `{{birthyear_be}}` `{{age}}` `{{house}}` `{{moo}}`
`{{community}}` `{{community_short}}` `{{tambon}}` `{{area}}` `{{area_label}}`
`{{amphoe}}` `{{province}}` `{{address}}`
`{{readbook}}` (หรือ `{{reading}}`) `{{pd}}` `{{va_r}}` `{{va_l}}` `{{va}}`
`{{shorthand}}` `{{longhand}}` `{{add}}` `{{cyl}}` `{{axt}}` `{{eyeproblem}}`
`{{screencode}}` `{{screening}}` `{{screening_short}}` `{{place}}`
`{{examdate}}` `{{examdate_short}}` `{{examdate_dmy}}` `{{r}}` `{{l}}` `{{lenstype}}`
`{{lens}}` `{{nameid}}`

token ที่เติม `_dash` จะแสดง `--/--` หรือ `--` เมื่อค่าในช่องนั้นว่าง:
`{{shorthand_dash}}` `{{longhand_dash}}` `{{add_dash}}` `{{cyl_dash}}` `{{axt_dash}}`
`{{va_r_dash}}` `{{va_l_dash}}` `{{pd_dash}}` `{{readbook_dash}}` `{{screening_short_dash}}`

`{{area}}` = ตำบล ถ้ามีตำบล ไม่งั้นใช้ชุมชน และ `{{area_label}}` = “ตำบล” หรือ “ชุมชน”
ตามค่าที่พบ — ช่วยให้แม่แบบเดียวใช้ได้ทั้งไฟล์เก่าและไฟล์ผลตรวจวัดสายตาชุดใหม่
`{{community_short}}` = ชุมชนโดยตัดคำว่า “ชุมชน” นำหน้าออก และจัด “หมู่ที่3” เป็น “หมู่ที่ 3”

### แม่แบบ 2×5

- **Sticker A4 2×5** — หน้าตาตามตัวอย่าง: ชื่อ-สกุล/อายุ, โลโก้และเลขที่,
  บ้านเลขที่/หมู่/ตำบล, `- สั้นR/L` / `+ ยาวR/L`, `อ่านหนังสือ`, `PD`, `VA/R`,
  `VA/L`, สถานที่และวันที่ตรวจ — ช่องที่ไม่มีค่าจะพิมพ์ขีด `--` หรือ `--/--` แทน
- **ผลตรวจสายตา A4 2×5** (ซ่อนอยู่ เปิดได้ผ่าน `onlyTemplate`) — โครงเดียวกัน
  แต่แสดง VA R/L, PD, อ่านหนังสือ และผลคัดกรองแบบสั้น สำหรับไฟล์หัวคอลัมน์ชุดใหม่

## 3. โครงสร้างไฟล์

```
web-app/
├─ index.html          ← ทางเข้า (พาไป login หรือ app ตามสถานะ)
├─ login.html          ← หน้าเข้าสู่ระบบ
├─ app.html            ← หน้าหลัก 3 ขั้นตอน
├─ css/app.css         ← สไตล์ทั้งหมด + สไตล์พิมพ์
├─ js/
│  ├─ config.js        ← ⚙ ตั้งค่าแอป + รหัสผ่าน (hash)
│  ├─ sha256.js        ← SHA-256 ใช้ได้ทุกเบราว์เซอร์
│  ├─ auth.js          ← ตรวจรหัสผ่าน/เซสชัน
│  ├─ fields.js        ← ฟิลด์ข้อมูล + token + จับคู่คอลัมน์
│  ├─ spreadsheet.js   ← อ่าน Excel/CSV
│  ├─ templates.js     ← แม่แบบป้าย (แสดงแบบเดียวตาม `onlyTemplate`)
│  ├─ renderer.js      ← วาดป้ายลง Canvas (ใช้ร่วมกันทุกเอาต์พุต)
│  ├─ pdf.js           ← สร้าง PDF + ดาวน์โหลด
│  └─ app.js           ← ตรรกะหน้าจอทั้งหมด
├─ libs/xlsx.full.min.js
├─ assets/logo-cross.png
├─ tools/password.html ← เครื่องมือสร้าง hash รหัสผ่านใหม่
├─ serve.js / start.bat ← เซิร์ฟเวอร์ทดสอบในเครื่อง
├─ _headers            ← security headers สำหรับ Cloudflare Pages
└─ robots.txt          ← ห้าม search engine เก็บหน้า
```

## 4. เปลี่ยนรหัสผ่าน

1. เปิด `tools/password.html` ผ่านเซิร์ฟเวอร์ทดสอบ (หรือเปิดไฟล์ตรง ๆ ก็ได้)
2. พิมพ์รหัสใหม่ → คัดลอกค่า SHA-256
3. เปิด `js/config.js` แก้บรรทัด

   ```js
   passwordHash: "ค่า hash ที่คัดลอกมา",
   ```

4. บันทึก แล้วอัปโหลด/commit ใหม่
5. แจ้งรหัสใหม่ให้ผู้ใช้ (รหัสเดิมใช้ไม่ได้ทันที)

ค่าเริ่มต้นในไฟล์คือ `sha256("sticker2569")`

## 5. ขึ้น GitHub + Cloudflare Pages

### 5.1 สร้าง repo

```bat
cd D:\ทำสติ๊กเกอร์
git init
git add web-app .gitignore
git commit -m "StickerPrint Web"
git branch -M main
git remote add origin https://github.com/<ชื่อบัญชี>/stickerprint-web.git
git push -u origin main
```

> **ห้าม** `git add .` ทั้งโฟลเดอร์ เพราะอาจมี `Sheet1.xls` / `.mdb` / ไฟล์ข้อมูลจริงติดขึ้นไป
> ใช้ `git add web-app .gitignore` เท่านั้น หรือตรวจ `git status` ก่อน commit

### 5.2 Cloudflare Pages

1. เข้า <https://dash.cloudflare.com> → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. เลือก repo `stickerprint-web` (private repo ก็ใช้ได้)
3. ตั้งค่า build:
   - **Framework preset:** None
   - **Build command:** *(เว้นว่าง)*
   - **Build output directory:** `web-app`
4. กด **Save and Deploy** → ได้ URL `https://stickerprint-web.pages.dev`

ทุกครั้งที่ push ขึ้น GitHub ไซต์จะอัปเดตอัตโนมัติ

### 5.3 ล็อกด้วย Cloudflare Access (ตัวเลือก แต่แนะนำ)

รหัสผ่านในเว็บเป็นเพียงการกันคนทั่วไป หากต้องการจำกัดเฉพาะผู้มีสิทธิ์จริง:

1. ต้องมี **custom domain** ผูกกับโปรเจกต์ก่อน (Access ใช้กับ `*.pages.dev` ไม่ได้)
2. Cloudflare dashboard → **Zero Trust** → **Access** → **Applications** → **Add an application** → **Self-hosted**
3. ตั้ง domain เป็นเว็บของคุณ และสร้าง policy เช่น **Emails** = รายชื่ออีเมลที่อนุญาต
4. ผู้ใช้จะต้องยืนยันตัวตน (อีเมล OTP / Google) ก่อนเห็นหน้าเว็บ

## 6. ข้อจำกัดด้านความปลอดภัย (อ่านก่อนใช้งานจริง)

- การล็อกอินนี้ทำงานในเบราว์เซอร์ (**client-side**) — ใครเปิดดูซอร์สโค้ดก็เห็นค่า hash
  และสามารถข้ามหน้า login ได้ด้วย DevTools
- จุดประสงค์คือ **กันคนทั่วไปที่ไม่มีรหัส** ไม่ใช่ระบบความปลอดภัยระดับองค์กร
- ข้อมูลที่พิมพ์ **ไม่ถูกส่งขึ้นเซิร์ฟเวอร์** และไม่ถูกเก็บใน `localStorage`
  (เก็บเฉพาะการตั้งค่า โลโก้ และตำแหน่งขยับ)
- หน้าเว็บถูกตั้ง `noindex` และ `robots.txt` ห้ามเก็บแล้ว แต่ URL ยังเข้าถึงได้ถ้ารู้
- หากต้องการความปลอดภัยจริง: ใช้ Cloudflare Access, ใส่รหัสผ่านที่หน้าเซิร์ฟเวอร์
  (Cloudflare Worker) หรือโฮสต์ในเครือข่ายภายใน

## 7. PDPA / ข้อมูลส่วนบุคคล

- **ห้าม commit** ไฟล์ข้อมูลจริง เช่น `Sheet1.xls`, `ข้อมูลดึง.xls`, `.mdb`, ไฟล์ CSV ที่มีชื่อ/เลขบัตรประชาชน
- ไฟล์ที่ผู้ใช้อัปโหลดจะอยู่ในหน่วยความจำของเบราว์เซอร์เท่านั้น รีเฟรชหน้าแล้วหายไป
- ควรแจ้งผู้ใช้ก่อนพิมพ์ว่าเอกสารมีข้อมูลส่วนบุคคล และเก็บกระดาษที่พิมพ์แล้วอย่างปลอดภัย
- หากใช้ Cloudflare Pages ข้อมูลที่วิ่งผ่านคือไฟล์เว็บ (HTML/JS) เท่านั้น ไม่ใช่ข้อมูล Excel

## 8. แก้ไข/พัฒนาเพิ่ม

- **เพิ่มแม่แบบ**: แก้ `js/templates.js` (โครงสร้างเหมือน `StickerPrint/templates/*.json`)
- **ปรับหน้าตา**: แก้ `css/app.css`
- **ปรับพฤติกรรม**: แก้ `js/app.js`
- **ทดสอบ**: `node serve.js` แล้วเปิดเบราว์เซอร์ (รีเฟรชได้ทันที ไม่ต้อง build)
- **ตรวจ PDF**: กด “บันทึกเป็น PDF” ในขั้นที่ 3 แล้วเปิดไฟล์ดู

### ค่าที่จำไว้ในเบราว์เซอร์ (`localStorage`)

| Key | เก็บอะไร |
|---|---|
| `sp_settings_v1` | แม่แบบที่เลือก, ค่าตั้งกระดาษ, token, ตำแหน่งขยับ |
| `sp_logo_v1` | รูปโลโก้ที่อัปโหลด (data URL) |
| `sp_auth_session` | เซสชันชั่วคราว (ปิดแท็บแล้วหาย) |
| `sp_auth_remember` | เซสชัน 30 วัน (เมื่อติ๊ก “จำฉันไว้”) |

ล้างทั้งหมดได้จาก DevTools → Application → Local Storage → Clear

## 9. อัปเดตเวอร์ชัน

แก้ `version` ใน `js/config.js` แล้ว commit — เลขจะแสดงที่หน้า login
